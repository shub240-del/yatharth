# V0.2 failure analysis

All findings are against provisional synthetic labels; human review is pending. Frozen Yatharth has 96 false negatives and 2 false positives. These are unresolved known gaps, not fixed bugs. All 98 binary decision mismatches have strict xfail regression cases. Category/severity/signal mismatches are measured separately and are not claimed covered by those binary assertions.

## Patterns and priority

| Diagnostic pattern | Cases |
|---|---|
| multilingual_coverage | 64 |
| adversarial_wording | 26 |
| missing_signal_or_indirect_request | 6 |
| contextual_negation_or_quotation | 2 |


The highest-priority candidate improvement is language-aware contextual evidence extraction, evaluated against independent human labels and a new untouched holdout at a fixed false-alert budget. Expanding regexes alone risks recreating the same vocabulary dependence. Separately test educational quotation/negation, indirect requests, misspellings, and implied authority. These are proposals, not implemented fixes.

Both false alerts are English safety education: C04-english (“Never send money to avoid arrest...”) and C05-english (“Scam awareness: criminals may say...”). Weighted risk words are present, but the speaker is warning against a scam. Conversely, Hindi/Hinglish signals are mostly absent from the English regex vocabulary. Low score therefore cannot establish safety.

The JSON failure ledger contains every A/A2/B binary false negative and false positive, including rule traces. Predictions.json contains all outputs for further category/severity review. The following appendix covers every B mismatch; explanations are code-grounded hypotheses requiring independent review.
